# 白璃 · Baili for Codex

Windows Codex 的非官方白龙娘启动动画、动态工作背景和 Q 版桌宠。公开版基于 v11，包含已获公开分发授权的音乐片段与人物素材。

启动影片为 **3840×2160 / 60fps / 16 秒**；进入工作界面后，背景中的品牌字、欢迎语、加载文字与横线在 **1.5 秒**内柔和淡出，随后播放无文字、静音的动态循环。保留柔和科技轮廓显现、渐变标题、星光、数字虹膜、眨眼与局部发束摆动。

这是二维素材合成与引导场形变，不是真实三维头发物理模拟。人物底图约 1672×940，4K 是输出尺寸；实际播放帧率取决于设备和客户端版本。

## 先了解风险

动画启动器会在已登录的官方 Codex 中打开仅监听 `127.0.0.1` 的调试端口，同机其他程序可能连接并控制客户端。**恢复外观不会关闭调试端口**；必须完全退出 Codex，再从原官方图标启动。不接受此风险，可以只使用独立预览、MP4 或桌宠。

本项目不修改官方程序文件、CSP、安全设置、系统执行策略或官方图标，不自动结束正在运行的 Codex。安装 Skill 本身不会接管官方启动事件：只有新增的 **Codex · 白璃动画** 快捷方式会触发动画，原官方入口保持原样。

## 使用动画

要求：Windows、官方签名的 Codex、Node.js 22.3+、PowerShell 7。无须 `npm install`。启动器优先复用已安装的 Codex PowerShell 7；也可用 `BAILI_POWERSHELL` 指向已有的 `pwsh.exe`。

1. 在本仓库页面选择 **Code → Download ZIP**，解压到一个长期保留的位置，不要在 ZIP 内直接运行。
2. 打开 `skills/codex-white-dragon-animation/assets/runtime`，双击 **Install-Shortcut.cmd**，创建独立的动画快捷方式。
3. 保存工作，完全退出 Codex（包括 Mini 和后台），双击桌面 **Codex · 白璃动画**。
4. 首次启动，亲自阅读提示并输入 `YES` 才继续。授权仅对同一 Windows 账户、同一官方版本和同一精确代码有效；绑定改变后会重新询问，不分发其他人的授权。

音乐默认静音，可在 **白璃 · 设置** 中启用后重播。`Esc` 跳过启动；`Ctrl+Alt+B` 打开外观设置。文字颜色跟随 Codex 主题；工作循环不再显示启动影片里的品牌字。

`Preview.cmd` 仅打开独立预览；`Start-Codex.cmd` 是显示错误信息的诊断启动入口。需要升级已有入口时，先阅读 [运行说明](skills/codex-white-dragon-animation/assets/runtime/README.md)，不要直接覆盖旧安装。

### 通过 Skill 安装

向 Codex 的 Skill Installer 提供本仓库 URL，并指定目录 `skills/codex-white-dragon-animation`。发现 Skill 后，使用 `$codex-white-dragon-animation` 请求安装。安装助手会把运行文件复制到独立目录，已有目录不会被覆盖，再在你授权后创建快捷方式；不会重启正在使用的客户端。

## 使用白璃桌宠

将本仓库的 `pets/baili` 文件夹复制到你的 Codex 数据目录的 `pets` 子目录，默认位置是 `%USERPROFILE%\.codex\pets\baili`。已有同名文件夹时先备份或改用其他位置，不要直接覆盖。随后在 Codex 的桌宠选择器中选择 **白璃**。

桌宠不是独立桌面 EXE，也不依赖动画启动器。包含眨眼待机、左右走路、挥手、跳跃、坐下、睡觉、思考和跟随鼠标视线等动作；何时播放由客户端状态决定。详见 [桌宠说明](pets/baili/README.md)。

## 恢复

- **白璃 · 设置 → 恢复原外观** 或 `Restore.cmd`：移除临时外观层，不修改聊天、主题或输入。
- `Remove-Shortcut.cmd`：只移除匹配本项目的快捷方式，保留官方入口。
- `Forget-Authorization.cmd`：撤销本机记住的授权。恢复/撤销都不会关闭现有调试端口，仍需完全退出 Codex。
- 移除桌宠时，仅移走自己安装的 `pets/baili` 文件夹，不要删除整个 Codex 数据目录。

## 开发与验证

在仓库根目录运行 `npm test`，检查安装流程及运行逻辑；不需要安装依赖。运行文件包含编辑/导出源码，`/?edit=1&qa=1` 是高负载编辑模式，正常启动只播放预渲染视频。

本地发布检查包含自动化测试与媒体完整性检查。浏览器预览或模拟宿主不等于官方客户端冷启动成功；更新客户端后应保存工作并自行复测。项目没有官方兼容性保证。
