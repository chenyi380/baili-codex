# 白璃 · Codex 动画 v11

2026-10-07。保留 v10 已验收的柔和显现、头发摆动、冷蓝外观、渐变标题、星光、眼睑和音乐。新增：进入工作界面后，背景上的四组品牌字、欢迎语、加载信息及横线在 1.5 秒内同步柔和淡出。之后循环不再显示它们，不改动 Codex 原生菜单、聊天和输入文字。保留 v10，非官方、可恢复，不修改官方程序文件、CSP、安全设置或系统执行策略。

## 视觉顺序

1. 0.10～1.65 秒：全轮廓的柔弱底光建立，多处发丝/轮廓错开点亮，没有从上向下的扫描边界。
2. 0.95～2.1 秒：整幅冷蓝材质柔和显现，和轮廓阶段交叠，不按高度擦除。
3. 1.5～3.1 秒：全局转入稳定材质、网格退去。六组发束从开始就错相摆动，根部固定、发梢有延迟；脸颊、眼睛、耳朵、龙角等区域不随发束移动。
4. 3.16～3.94 秒：连续睁眼；网格已退去，数字虹膜被不透明眼睑几何揭开。
5. 1.4 秒起星光进入；Codex 描边与渐变填色和人物交叠，约 4.5 秒标题及副标题完成。10.7 秒和 13.86 秒附近保留短眨眼；16 秒启动结束时保留文字，以便进入工作界面后继续完成一次淡出，而不是先消失再重新闪现。音乐末尾淡出保持原样。
6. 工作界面入场 0～1.5 秒：所有背景文字及横线同时平滑淡出，人物、眼内数据、头发及星光保持连续运动。工作入场只播放一次，不在每轮循环重播；选择减少动态则直接进入无文字背景。

工作壁纸采用同一完成材质、多发束错相摆动、数字虹膜和星光，不含任何品牌或欢迎/加载文字，单视频静音循环。发束主周期约 3.2 秒、叠加周期约 5.33 秒，组成 16 秒周期。入场和循环的运动时间相接，不混合不同时间的人脸，也不依靠整张图晃动。

显现素材是 `assets/style-contours.png` 和 `assets/style-material.png`，对应已确认样张；公开包不包含私人制作记录或原参考文件。标题文字由代码单独合成，不依赖生成图中文字。

启动 `startup.mp4` 与循环 `wallpaper.mp4` 均为 **3840×2160 / 60fps / 16 秒 / 960 帧**；一次性的 `handoff.mp4` 为 **3840×2160 / 60fps / 1.5 秒 / 90 帧**，无音轨。素材约 1672×940，4K 是输出尺寸，不是原生 4K 人物/三维工程。仍为二维素材合成与引导场形变，**不是真实三维头发物理、透明发束拆层或原片逐帧重建**。运行时只有一个视频在播放，不做双人脸交叉淡化；高负载 GPU 合成仅用于编辑和导出。

## 怎么运行

保存工作，完全退出 Codex（包括 Mini/后台），再双击桌面 **Codex · 白璃动画**。官方原图标保留，不触发本项目动画。

首次安装运行 `Install-Shortcut.cmd`；已有 v10 时显式升级：

```powershell
node shortcut.mjs --install --upgrade-from="v10 的绝对路径"
```

只覆盖已知旧项目入口并先备份，不覆盖不同程序的同名入口。`Start-Codex.cmd` 是可见诊断入口；`Preview.cmd` 是独立预览；MP4 仅播放影片。客户端运行时拒绝重复启动，不自动结束进程。

新版首次需输入一次 **YES**：记住的授权只适用于同账户、同官方版本、同精确代码；不会迁移旧授权。后续相同绑定不必再输入。音乐默认静音，设置里启用后重播；Esc 可跳过启动。

右下角 **白璃 · 设置** / Ctrl+Alt+B 提供重播、暂停、背景/面板透明度、减少动态和恢复。字体仍跟随 Codex 主题。

## 预览与验证

`node server.mjs` 或 `Preview.cmd` 打开本机预览。默认播放预渲染视频；“进入工作界面”播放一次淡出后进入干净循环；入场关键帧可比较 0 秒、0.75 秒及 1.5 秒。“测量完整播放”记录 16 秒启动的帧数、丢帧、耗时和长任务；不包含额外的 1.5 秒工作淡出。请保持页面可见，统计不是物理屏幕刷新率保证。

`/?edit=1&qa=1` 是高负载逐帧编辑/导出，不是客户端播放路径。`npm test` 是本包测试；浏览器预览或模拟宿主不能证明官方客户端冷启动。请在保存工作并完全退出后自行复测新版入口，不要为测试强制结束正在使用的客户端。

## 本机调试端口风险

动画入口在已登录 Codex 打开仅监听 127.0.0.1 的调试端口，同机其他程序可能连接并控制客户端。恢复外观、撤销授权、关闭辅助启动器**不会关闭已打开端口**。完全退出 Codex，再从原官方图标启动，才恢复无该端口的运行方式。不接受此风险，请只看独立预览或 MP4。

“恢复原外观”或 `Restore.cmd` 只移除本项目外观层、视频、控件、样式和监听，不改聊天、主题、输入或官方文件。

前提：Windows、官方签名 Codex、Node.js 22.3+、PowerShell 7。复用已有 Codex PowerShell 7，不绕过执行策略。
