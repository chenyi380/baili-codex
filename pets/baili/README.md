# 白璃桌宠

温柔活泼的 Q 版白龙娘：白色长发和龙角、淡紫白龙翼、龙尾、白色长裙。

## 安装

1. 找到 Codex 数据目录；默认是 `%USERPROFILE%\.codex`，如果你设置了 `CODEX_HOME`，使用对应的数据目录。
2. 将本项目的整个 `pets/baili` 文件夹复制到数据目录的 `pets` 文件夹，使 `pet.json` 和 `spritesheet.webp` 位于同一个 `baili` 目录。
3. 如果已有同名目录，先备份，不直接覆盖。在 Codex 的桌宠选择器中选择 **白璃**。

这是 Codex 使用的桌宠资源，不是独立 EXE；不需要动画启动器或本机调试端口。客户端是否支持此资源格式取决于版本。复制文件不会自动选择桌宠，也不应该因此强制重启正在使用的 Codex。

## 动作与格式

图集为 1536×2288 的透明 WebP，8 列 × 11 行，每帧 192×208；`pet.json` 使用 `spriteVersionNumber: 2`。

包含眨眼/呼吸待机、左右走路、挥手、跳跃、坐下等待、睡觉、工作思考、查看结果，以及 16 个方向的鼠标注视。动作何时播放由 Codex 状态与交互决定，不是独立的聊天人格或定时睡眠服务。

移除时，仅移走自己安装的 `pets/baili` 目录；不要删除整个 Codex 数据目录。素材使用范围见仓库根目录的 `ASSET-NOTICE.md`，图集不是 MIT 代码。
